# Image assets

This project uses the official, original PNG files from the haX.baby Track 1: Pip the Skull Baby creator asset pack. They are stored locally in `src/assets/` and imported directly by the React components. The application does not depend on Lovable-hosted image URLs.

Original files: `pip_avatar_cloud.png`, `pip_dream_lantern.png`, `pip_lullaby_box.png`, and `pip_portrait.png`.
